# Product Detail Page Rules

## Overview

Amazon has strict standards for product detail pages, covering titles, images, bullet points, A+ content, and variations. Violating detail page rules may be classified as "Detail Page Abuse," resulting in listing removal or even account deactivation.

---

## Title Requirements

| Rule | Description |
|------|------|
| **Maximum length** | 200 characters (including spaces); Amazon recommends keeping it under 80 characters |
| **Recommended format** | Brand + product name + key features + size/quantity |
| **Capitalization** | Use proper capitalization; all caps (ALL CAPS) is prohibited |
| **Number format** | Use Arabic numerals such as "2" rather than "two" |
| **Prohibited content** | HTML tags, special symbols (! * $ ?), promotional phrases such as "free shipping" or "100% quality guarantee" |
| **Prohibited information** | Seller name, URLs, marketing messages |
| **Plain text** | Must not contain any HTML formatting |

### Title Examples
- ✅ Correct: `XYZ Brand Wireless Bluetooth Headphones - Noise Cancelling, 40H Battery Life, Black`
- ❌ Incorrect: `***BEST*** XYZ Headphones!!! Free Shipping!!! BEST DEAL ON AMAZON!!!`

---

## Main Image Requirements

| Rule | Description |
|------|------|
| **Background** | Pure white (RGB 255, 255, 255) |
| **Resolution** | At least 1000 x 1000 pixels (a longest side of 1600+ pixels is recommended to enable the zoom function) |
| **Product coverage** | The product must fill at least 85% of the frame |
| **What to show** | Show only the item for sale, with no accessories or props that are not included |
| **Prohibited content** | No text overlays, no watermarks, no borders, no logos, no URLs |
| **Prohibited styles** | No colored backgrounds, no graphic illustrations, no animated images |
| **Prohibited elements** | No models/mannequins (except for lifestyle images), no line drawings |
| **Format** | JPEG (recommended), TIFF (.tif), or PNG (.png) |
| **One product per image** | Show only one product per image (do not show multiple colors/angles in a single image) |

### Common Image Violations
- Non-pure-white background: product placed on a colored or gray background
- Insufficient product coverage: the product is too small, leaving too much empty space
- Promotional text on the image: "50% OFF," "Best Seller," etc.
- Including accessories that are not sold with the product
- Using a lifestyle image (a non-white-background scene shot) as the main image

---

## Bullet Points Requirements

| Rule | Description |
|------|------|
| **Quantity** | 3-5 (some categories require exactly 5) |
| **Length per bullet** | Maximum 500 characters |
| **Content focus** | Focus on product benefits, not just features |
| **Format** | Start each bullet with a capital letter |
| **Prohibited content** | No promotional language, no pricing information, no inventory information, no shipping information |
| **Prohibited elements** | No HTML, no quotation marks, no customer testimonials, no review solicitations |

### Best Practices
- Have each bullet address a single customer pain point
- Highlight what problem the product solves
- Include use cases
- Use specific data and comparisons (such as "30% lighter than the standard version")
- Put the most important information in the first bullet

---

## Product Description Requirements

| Rule | Description |
|------|------|
| **Maximum length** | 2000 characters (varies in some categories) |
| **Allowed HTML** | Only the `<br>` line break tag is allowed |
| **Prohibited content** | No promotional copy, no pricing, no shipping information |
| **Prohibited elements** | No JavaScript, no other scripts, no external links |
| **Content requirements** | Comprehensive product information to help customers make a purchase decision |

### A+ Content (Enhanced Brand Content / A+ Content)
- Available only to Brand Registry sellers
- Includes enhanced images, comparison tables, and brand story modules
- Must comply with A+ content guidelines (no promotional claims, no guarantee/warranty statements, no links)

---

## Variation Rules

| Rule | Description |
|------|------|
| **Valid variation themes** | Color, size, style, flavor, etc. (must be within Amazon-approved variation themes) |
| **Prohibited behavior** | Bundling unrelated products as variations, or tying together different product styles |
| **Consequences** | Classified as "variation abuse"; the listing may be split or removed |
| **Requirement** | All child variations under a parent must essentially be the same product |

### Common Variation Violations
- Tying together products of different styles/functions
- Using incorrect variation themes (for example, setting a color difference as a size variation)
- Adding inconsistent information in variation titles

---

## Search Terms / Backend Keywords

| Rule | Description |
|------|------|
| **Maximum length** | 250 bytes (not characters) |
| **Duplication rule** | Do not repeat words already in the title |
| **Separators** | Separate with spaces; commas are not needed |
| **Prohibited content** | No brand names (unless it is your own brand), no ASINs, no temporary claims |
| **Case-insensitive** | Handled automatically by the system |

---

## General Detail Page Rules

| Rule | Description |
|------|------|
| **No code** | Detail pages must not contain HTML, JavaScript, or other code (except `<br>`) |
| **Prohibited content** | No obscene/offensive material, no phone numbers, no email addresses, no URLs |
| **Prohibited information** | No time-sensitive information (tour dates, seminars, etc.) |
| **No promotion** | No cross-selling or cross-promotion |
| **Category accuracy** | Products must be accurately placed in the correct browse tree category |
| **No duplicates** | Do not create duplicate pages for products already in Amazon's catalog |
| **International products** | International products must be listed on the correct country marketplace detail page |

---

## Consequences of Violations

| Violation Type | Penalty |
|---------|------|
| Minor violation (non-compliant title/image) | Listing suppressed or removed |
| Moderate violation (detail page abuse) | Listing removal + account warning |
| Severe violation (variation abuse, duplicate creation) | Account privileges restricted or deactivated |
| Repeated violations | Selling privileges permanently removed |
