# Shopify 图片、媒体与商品变体规范 (Media & Variants Rules)

## 概述

Shopify 对商品媒体（图片、视频、3D 模型）的格式、大小与数量有明确限制，对变体的选项数量与组合数也有结构性上限。超过媒体上限会导致无法上传，变体超限则无法在前台正常展示。了解这些限制是保证商品详情页完整展示的前提。

---

## 图片规格 (Image Requirements)

| 规则 | 说明 |
|------|------|
| **单文件大小上限** | **20 MB** |
| **最大像素** | Shopify 帮助中心：最大 **5000 × 5000 px 或 2500 万像素**；开发者文档（GraphQL Admin API）标注 **4472 × 4472 px（约 2000 万像素）**，两者口径略有差异 |
| **支持格式** | JPEG、PNG、GIF、WEBP、HEIC |
| **推荐尺寸** | **2048 × 2048 px**，宽高比 **1:1（正方形）** |
| **推荐体积** | 建议压缩至 **500 KB 以内**；WebP 比 JPEG 小 25%–35% |
| **宽高比处理** | 主题按 1:1 设计；非正方形图片会被裁剪、加边框或拉伸 |
| **透明背景** | 需要透明时使用 PNG，否则优先 JPEG/WebP |
| **缩放** | 分辨率越高越支持放大查看，但需与页面加载速度平衡 |

---

## 主图与图集 (Featured Image & Gallery)

| 规则 | 说明 |
|------|------|
| **特色图（Featured image）** | 商品媒体列表中的**第一个媒体**，用于集合页、购物车、结账页与首页 |
| **更换主图** | 在后台拖动媒体排序即可更换特色图 |
| **图集顺序** | 建议主图 → 场景图 → 细节图 → 尺寸/规格图 → 包装图 |
| **每变体主图** | 每个变体可指定一张专属图片（变体图片）；同一变体通常只支持一张主图 |
| **Alt 文本** | 每张图应填写描述性 alt 文本，利于 SEO 与无障碍访问 |
| **图片一致性** | 主图与图集风格、光源、背景应统一 |

---

## 视频规范 (Video Requirements)

| 规则 | 说明 |
|------|------|
| **单文件大小上限** | **1 GB** |
| **时长** | 最长 **10 分钟**，最短 **0.25 秒** |
| **支持格式** | MOV、MP4、WEBM |
| **分辨率** | 最高 4K（宽/高均不超过 4096 px），最低 100 px |
| **帧率** | 最高 120 fps |
| **推荐实践** | 单个片段建议 30 秒至 2 分钟，控制体积以保证加载速度 |

---

## 3D 模型规范 (3D Model Requirements)

| 规则 | 说明 |
|------|------|
| **上传格式** | GLB |
| **服务输出格式** | GLB 与 USDZ（供 iOS AR 使用）|
| **文件大小上限** | **15 MB** 以内 |
| **适用场景** | 家具、鞋类、消费电子等需多角度查看的商品 |

---

## 媒体数量与套餐限制 (Media Limits by Plan)

| 限制项 | 数值 |
|--------|------|
| **每商品媒体总数** | 最多 **250 个**（图片 + 视频 + 3D 模型合计）|
| **视频与 3D 模型数量** | Basic/Starter 250；Grow 1,000；Advanced 5,000；Plus/Enterprise 50,000 |
| **视频存储空间** | Basic 50 GB；Grow/Advanced 500 GB；Enterprise 2 TB |
| **店铺文件总存储** | Basic 100 GB；Grow 300 GB；Advanced 500 GB；Plus 1 TB；Enterprise 10 TB |
| **变体上限提升不改变媒体上限** | 变体上限提升至 2048 后，250 的媒体上限**未同步提高** |

---

## 变体结构 (Variant Options)

| 规则 | 说明 |
|------|------|
| **选项数量上限（默认）** | 每个商品最多 **3 个选项**（如 Size、Color、Material）|
| **选项名称/值长度** | 每个选项名称或值最长 **255 个字符** |
| **变体总数上限（默认）** | 每个商品最多 **100 个变体**（各选项组合总数不得超过 100）|
| **扩展变体上限** | Shopify 已推出扩展变体（Extended Variants），通过 GraphQL API 支持最多 **2048 个变体**；该能力目前面向开发商店/开发者预览，后台对正式店铺仍以 100 为默认上限 |
| **前台渲染** | Liquid 主题在商品页仅渲染前 **250 个变体** |
| **变体 URL** | 通过 `?variant=<id>` 参数直达指定变体 |

### 变体最佳实践
- 组合数超 100 时：按主选项拆分为多个商品，或用变体应用扩展
- 移除不存在的组合（并非每个颜色都有每种材质），减少组合数
- 同一商品的变体必须是本质相同的商品，不相关商品不得绑为变体
- 变体之间价格、库存、重量、SKU 可独立设置

## SKU 与条码 (SKU & Barcode)

| 字段 | 规则 |
|------|------|
| **SKU 长度** | 建议 ≤ **16 个字符**（4–8 字符在多数目录中更实用）|
| **SKU 唯一性** | 同一店铺内应唯一；使用 Shopify Fulfillment Network（SFN）时**强制唯一** |
| **SKU 字符** | 使用数字或数字+字母组合；避免特殊符号、空格及易混淆字符（0/O、1/I）|
| **条码数量** | 每个变体最多 **20 个条码**，每条最多 **255 个字符** |
| **条码类型** | UPC、EAN、ISBN、GTIN、ASIN；声明类型后系统会按标准校验 |
| **条码唯一性** | 各变体应使用不同条码，尤其是独立管理库存时 |
| **SFN 要求** | 每个 SKU 最多支持 5 个条码，且需要含 GTIN 的行业标准条码 |

---

## 违规后果

| 问题 | 后果 |
|------|------|
| 图片超尺寸/超体积 | 无法上传，或系统自动压缩导致画质损失 |
| 图片尺寸不符主题比例 | 前台被裁剪、留白或拉伸，影响转化 |
| 媒体超过 250 个 | 无法继续上传 |
| 变体超过 100 个（默认）| 无法创建新变体，或前台展示异常 |
| SKU/条码重复 | 库存与渠道对接出错，SFN 商品被拒 |

## Listing 合规检查清单

### 图片
- [ ] 单文件 ≤ 20 MB，像素不超过平台上限
- [ ] 推荐 2048 × 2048 px，宽高比 1:1
- [ ] 格式为 JPEG/PNG/WEBP/GIF/HEIC 之一
- [ ] 已压缩至 500 KB 以内（建议）
- [ ] 每张图已填写 alt 文本

### 主图与图集
- [ ] 第一个媒体为合格特色图
- [ ] 图集顺序为 主图 → 场景 → 细节 → 规格 → 包装
- [ ] 每个变体已指定专属图片（如适用）

### 视频与 3D
- [ ] 视频 ≤ 1 GB、≤ 10 分钟，格式为 MOV/MP4/WEBM
- [ ] 3D 模型为 GLB 且 ≤ 15 MB
- [ ] 每商品媒体总数 ≤ 250

### 变体
- [ ] 选项数 ≤ 3，变体数 ≤ 100（或已使用扩展变体）
- [ ] 选项名称与值 ≤ 255 字符
- [ ] 已移除不存在的组合
- [ ] 变体均属同一本质商品

### SKU 与条码
- [ ] SKU 简短（建议 ≤ 16 字符）且店铺内唯一
- [ ] 条码 ≤ 20 条/变体，每条 ≤ 255 字符
- [ ] SFN 商品已配置唯一 SKU 与 GTIN
