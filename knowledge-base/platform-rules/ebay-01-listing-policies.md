# eBay 上架政策与卖家标准 (eBay Listing Policies and Seller Standards)

## 概述

eBay 对刊登形式、卖家表现和重复刊登有明确规范。本文件（基于 eBay US 站点，其他站点差异见文内标注）说明拍卖/一口价的刊登选择、Seller Standards 的不良交易率等指标阈值、重复刊登判定，以及 Best Offer、Get it Fast 和处理时间要求。违反刊登政策可能导致 Listing 被隐藏或移除、费用没收，严重或重复违规会导致销售权限受限甚至账户停用。

---

## Listing 形式 (Listing Formats)

| 规则 | 说明 |
|------|------|
| **拍卖式 (Auction-style)** | 设定起拍价，买家竞价，结束时最高出价者获胜 |
| **拍卖时长** | 1、3、5、7、10 天；7 天为最常见选择；1 天拍卖需反馈分 ≥ 10 且部分类目不可用 |
| **一口价 (Fixed Price)** | 固定价格直接购买，通常 30 天，也可使用 Good 'Til Cancelled (GTC) 自动续期 |
| **Buy It Now 搭配拍卖** | 首个出价出现前显示；买家使用后拍卖立即结束 |
| **BIN 价格下限** | 多数类目 BIN 价格须高出起拍价至少 **30%**；eBay UK 为 **40%** |
| **底价 (Reserve Price)** | 可选，需额外付费；未达底价则流拍 |

## 刊登政策 (Listing Policies)

| 规则 | 说明 |
|------|------|
| **准确归类** | 商品必须归入正确的 eBay 类目 |
| **信息真实** | 标题、副标题、图片、物品属性必须 100% 准确，不得误导买家 |
| **禁止规避费用** | 不得在刊登中引导买家站外成交、不得虚高运费 |
| **禁止联系方式** | 成交前不得在标题、描述、图片中提供电话、邮箱、社交账号、外部网址 |
| **禁止操纵搜索** | 不得关键词堆砌、品牌堆叠、使用 "not XXX" 等对比词 |
| **履约义务** | 必须按刊登承诺的处理时间和物流方式发货 |

## 卖家表现标准 (Seller Standards)

eBay 每月 **20 日**评估一次；评估窗口为：近期成交量 ≥ 400 笔时取**最近 3 个月**，否则取**最近 12 个月**。

| 指标 | Top Rated 要求 | Below Standard 触发线 |
|------|---------------|---------------------|
| **不良交易率 (Transaction Defect Rate)** | ≤ **0.5%**，且涉及不超过 3 位不同买家 | > **2%** |
| **未解决纠纷率 (Cases Closed Without Seller Resolution)** | ≤ **0.3%** 或不超过 2 笔（取较高者）| > **0.3%** |
| **迟发率 (Late Shipment Rate)** | ≤ **3%** 或不超过 5 笔 | 一般不单独触发，但影响曝光 |
| **按时上传跟踪号 (Tracking Uploaded On Time)** | ≥ **95%**，且承运商可验证 | — |

- **Above Standard**：介于上述两者之间（如不良交易率 0.5%–2%）。
- **Top Rated Seller 附加门槛**：账户活跃 ≥ 90 天，近 12 个月 ≥ 100 笔交易且销售额 ≥ $1,000。
- **Top Rated Plus**（Listing 级，可享 **10% 成交费折扣**）：需同日或 1 个工作日处理时间 + 30 天或更长退货期（含免费退货运费）。
- 卖家自行取消订单（如缺货）和未解决纠纷均计入不良交易。

## 重复刊登政策 (Duplicate Listings)

| 规则 | 说明 |
|------|------|
| **核心禁令** | 同一卖家不得同时发布多于一条**完全相同的**一口价 Listing |
| **多件相同商品** | 使用**一条一口价 Listing + 设置数量**，禁止拆成多条 |
| **单件商品** | 只能有一条 Listing |
| **变体商品** | 颜色/尺寸等变体必须在**一条带变体的 Listing** 中刊登 |
| **多机型配件例外** | 适配多个设备的相同配件，最多允许 **5 条**一口价 Listing，且每条须按适配品牌/型号区分 |
| **通用商品例外** | 通用商品（如 AA 电池）不适用上述例外，不得多条刊登 |
| **拍卖式重复** | 多条相同拍卖允许，但需起拍价、底价、标题、描述一致且不使用 BIN；一次仅一条无出价者对外可见 |
| **跨站点** | 不同 eBay 站点可分别刊登同一商品 |

违反后果：移除 Listing、警告、限制账户活动或停用账户。

## Get it Fast 与处理时间 (Handling Time)

| 规则 | 说明 |
|------|------|
| **处理时间定义** | 从收到付款到交给承运商的时间 |
| **1 个工作日** | 无截单时间；订单确认后须在**次一工作日的 23:59 前**交给承运商 |
| **同日处理 (0 天)** | 有截单时间，默认**当地时间 14:00**；截单前订单当日发出 |
| **Get it Fast 条件** | 仅限一口价或带 BIN 的拍卖；须提供至少一项**美国境内一日达**物流；处理时间须为 **0 或 1** |
| **限制** | Get it Fast 不适用于国际物流 |
| **延迟处理** | 处理时间 ≥ 4 个工作日被视为"延长处理"，影响买家观感与曝光 |

## Best Offer（议价）

| 规则 | 说明 |
|------|------|
| **适用形式** | 主要用于一口价；带 BIN 的拍卖加入后，首个出价会使其失效 |
| **自动接受价** | 达到或高于该价格的出价自动成交，须低于 BIN 价格 |
| **自动拒绝价** | 低于该价格的出价自动拒绝，买家看不到该阈值 |
| **区间内出价** | 位于两阈值之间的出价需卖家手动处理（接受/拒绝/还价） |
| **买家出价次数** | 多数类目每件商品最多 3 次（部分站点/类目为 5 次）|
| **出价有效期** | 卖家未回应时出价会过期（约 24–48 小时）或至 Listing 结束 |
| **费用** | 成交后仍按实际成交价收取成交费 |

---

## 违规后果

| 违规类型 | 处罚 |
|---------|------|
| 轻度（标题/属性不规范）| Listing 被隐藏或移除 |
| 中度（刊登政策/关键词堆砌）| Listing 移除 + 账户警告 + 没收费用 |
| 严重（重复刊登、规避费用）| 销售权限受限、丧失 PowerSeller 资格 |
| 多次或屡犯 | 账户停用、永久移除销售权限 |

## Listing 合规检查清单

### 刊登形式
- [ ] 拍卖时长在 1/3/5/7/10 天内
- [ ] BIN 价格高出起拍价 ≥ 30%（US）
- [ ] 一口价使用数量而非多条重复刊登

### 卖家表现
- [ ] 不良交易率 ≤ 0.5%（Top Rated）
- [ ] 未解决纠纷率 ≤ 0.3%
- [ ] 迟发率 ≤ 3%
- [ ] 按时上传跟踪号率 ≥ 95%

### 重复刊登
- [ ] 同一商品仅一条一口价 Listing
- [ ] 多件商品用数量字段而非多条
- [ ] 变体合并在一条带变体 Listing 中
- [ ] 多机型配件不超过 5 条且按品牌/型号区分

### Get it Fast / 处理时间
- [ ] 处理时间已明确（0 或 1 个工作日）
- [ ] Get it Fast 仅用于美国境内一日达
- [ ] 物流方式与买家所选一致

### Best Offer
- [ ] 自动接受价低于 BIN 价格
- [ ] 自动拒绝价设置合理
- [ ] 已确认类目支持自动接受/拒绝

### 刊登政策
- [ ] 商品归入正确类目
- [ ] 无站外链接或联系方式
- [ ] 无关键词堆砌或品牌对比词
