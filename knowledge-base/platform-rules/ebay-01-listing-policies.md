# eBay Listing Policies and Seller Standards

## Overview

eBay enforces explicit rules on listing formats, seller performance, and duplicate listings. This document (based on the eBay US site; other-site differences are noted inline) covers auction vs. Fixed Price selection, Seller Standards thresholds such as the transaction defect rate, duplicate listing determinations, and Best Offer, Get it Fast, and handling time requirements. Violations can lead to listings being hidden or removed, forfeited fees, restricted selling privileges, or account suspension.

---

## Listing Formats

| Rule | Description |
|------|------|
| **Auction-style** | Set a starting price; buyers bid; highest bidder wins at close |
| **Auction duration** | 1, 3, 5, 7, or 10 days; 7 days is most common; 1-day auctions require a feedback score ≥ 10 and are unavailable in some categories |
| **Fixed Price** | Set price for immediate purchase, typically 30 days, or Good 'Til Cancelled (GTC) for automatic renewal |
| **Buy It Now with auction** | Shown until the first bid; once a buyer uses it, the auction ends immediately |
| **BIN price floor** | In most categories the BIN price must be at least **30%** above the starting price; on eBay UK, **40%** |
| **Reserve Price** | Optional, extra fee; if the reserve is not met, the item does not sell |

---

## Listing Policies

| Rule | Description |
|------|------|
| **Accurate categorization** | Items must be listed in the correct eBay category |
| **Truthful information** | Title, subtitle, images, and item specifics must be 100% accurate and must not mislead buyers |
| **No fee avoidance** | No directing buyers to complete transactions off eBay; no inflated shipping charges |
| **No contact information** | Before a sale, no phone numbers, email addresses, social accounts, or external URLs in title, description, or images |
| **No search manipulation** | No keyword stuffing, brand stacking, or comparison terms such as "not XXX" |
| **Fulfillment obligation** | Ship using the handling time and shipping method promised in the listing |

## Seller Standards

eBay evaluates sellers once a month on the **20th**; the evaluation window is the **most recent 3 months** if recent transaction volume is ≥ 400, otherwise the **most recent 12 months**.

| Metric | Top Rated requirement | Below Standard threshold |
|------|---------------|---------------------|
| **Transaction Defect Rate** | ≤ **0.5%**, involving no more than 3 different buyers | > **2%** |
| **Cases Closed Without Seller Resolution** | ≤ **0.3%** or no more than 2 cases (whichever is higher) | > **0.3%** |
| **Late Shipment Rate** | ≤ **3%** or no more than 5 shipments | Generally does not trigger status alone, but affects visibility |
| **Tracking Uploaded On Time** | ≥ **95%**, verifiable by the carrier | — |

- **Above Standard**: between the two levels above (for example, a transaction defect rate of 0.5%–2%).
- **Additional Top Rated Seller thresholds**: account active ≥ 90 days; ≥ 100 transactions and ≥ $1,000 in sales over the last 12 months.
- **Top Rated Plus** (listing level, qualifies for a **10% final value fee discount**): requires same-day or 1-business-day handling plus a 30-day or longer return period (including free return shipping).
- Seller-cancelled orders (for example, out of stock) and unresolved cases both count as transaction defects.

## Duplicate Listings Policy

| Rule | Description |
|------|------|
| **Core prohibition** | A seller may not have more than one **identical** Fixed Price listing active at the same time |
| **Multiple identical items** | Use **one Fixed Price listing with a quantity**, not multiple listings |
| **Single item** | Only one listing allowed |
| **Variation items** | Variants such as color or size must be listed in **one listing with variations** |
| **Multi-device accessory exception** | The same accessory fitting multiple devices may have up to **5** Fixed Price listings, each differentiated by compatible brand/model |
| **Generic item exception** | Generic items (such as AA batteries) do not qualify and may not be listed multiple times |
| **Auction duplicates** | Multiple identical auctions are allowed, but must share starting price, reserve price, title, and description, and must not use BIN; only one listing without bids is visible at a time |
| **Cross-site** | The same item may be listed separately on different eBay sites |

Consequences: listing removal, warnings, restricted account activity, or account suspension.

## Get it Fast and Handling Time

| Rule | Description |
|------|------|
| **Handling time definition** | Time from receiving payment to handing the item to the carrier |
| **1 business day** | No cutoff time; item must reach the carrier by **23:59 on the next business day** after order confirmation |
| **Same-day handling (0 days)** | Has a cutoff time, default **14:00 local time**; orders before the cutoff ship the same day |
| **Get it Fast requirements** | Limited to Fixed Price or auction listings with BIN; must offer at least one **domestic US one-day** shipping service; handling time must be **0 or 1** |
| **Restriction** | Get it Fast does not apply to international shipping |
| **Extended handling** | A handling time ≥ 4 business days is "extended handling", affecting buyer perception and visibility |

---

## Best Offer

| Rule | Description |
|------|------|
| **Applicable formats** | Mainly Fixed Price; if added to an auction with BIN, the first bid voids it |
| **Auto-accept price** | Offers at or above this price are accepted automatically; must be below the BIN price |
| **Auto-decline price** | Offers below this price are declined automatically; buyers cannot see the threshold |
| **Offers in between** | Offers between the two thresholds require manual seller action (accept / decline / counteroffer) |
| **Buyer offer limit** | In most categories, up to 3 offers per item (5 on some sites/categories) |
| **Offer expiration** | If the seller does not respond, offers expire (roughly 24–48 hours) or when the listing ends |
| **Fees** | A final value fee still applies on the actual sale price |

---

## Consequences of Violation

| Violation type | Penalty |
|---------|------|
| Minor (irregular title or item specifics) | Listing hidden or removed |
| Moderate (listing policy violation or keyword stuffing) | Listing removal + account warning + forfeited fees |
| Serious (duplicate listings, fee avoidance) | Restricted selling privileges, loss of PowerSeller status |
| Repeated or persistent | Account suspension, permanent removal of selling privileges |

## Listing Compliance Checklist

### Listing formats
- [ ] Auction duration within 1/3/5/7/10 days
- [ ] BIN price ≥ 30% above the starting price (US)
- [ ] Fixed Price listings use quantity rather than duplicate listings

### Seller performance
- [ ] Transaction defect rate ≤ 0.5% (Top Rated)
- [ ] Cases closed without seller resolution ≤ 0.3%
- [ ] Late shipment rate ≤ 3%
- [ ] Tracking uploaded on time ≥ 95%

### Duplicate listings
- [ ] One Fixed Price listing per item
- [ ] Multiple items use the quantity field, not multiple listings
- [ ] Variations combined into one listing with variations
- [ ] Multi-device accessories within 5 listings, differentiated by brand/model

### Get it Fast / Handling time
- [ ] Handling time specified (0 or 1 business day)
- [ ] Get it Fast used only for domestic US one-day shipping
- [ ] Shipping service matches the buyer's selection

### Best Offer
- [ ] Auto-accept price below the BIN price
- [ ] Auto-decline price set reasonably
- [ ] Category confirmed to support auto-accept/auto-decline

### Listing policies
- [ ] Items in the correct category
- [ ] No off-site links or contact information
- [ ] No keyword stuffing or brand comparison terms
