# eBay Images and Description Rules

## Overview

Images are the primary factor in eBay buyer decisions, while the description carries the complete item information. This document (based on the eBay US site) covers free image quantity, size and format requirements, prohibited photo content, and the HTML allowed in descriptions as well as prohibited Active Content, external links, and contact information. Watermarked images can keep a listing out of search results, descriptions with violating content are hidden or removed, and repeated violations restrict selling privileges.

---

## Image Quantity

| Rule | Description |
|------|------|
| **Free quantity** | Up to **24** images free per listing (1 main image + 23 additional), except in some categories |
| **Platform support** | 24 free images supported on desktop, mobile, and the eBay app |
| **Recommended quantity** | At least 2; 6 or more recommended; 3 or more noticeably improves conversion |
| **Main image** | The first image is the main image (Gallery Image), shown in search results |

---

## Image Size and Format

| Rule | Description |
|------|------|
| **Minimum size** | Longest side at least **500 pixels**; anything smaller is rejected |
| **Recommended size** | **800–1600 pixels**; **1600 pixels** gives the best Zoom experience and easy detail viewing on mobile |
| **Zoom feature** | Zoom generally requires a longest side of at least **800 pixels** (some categories are higher, so using 1600px directly is recommended) |
| **File size** | Up to **7 MB** per image from a computer; up to **12 MB** when fetched from a URL |
| **Formats** | JPEG, PNG, GIF, TIFF, BMP, WEBP, HEIC, AVIF; **JPEG is most recommended** (small file, high quality) |
| **Format limits** | Animated GIFs are not supported |

---

## Photo Requirements

| Rule | Description |
|------|------|
| **Background** | A **plain white or neutral background** is recommended; for reflective items (such as jewelry) a black background can highlight texture |
| **Actual photo requirement** | Used or pre-owned items **must use actual photos of the item** |
| **Stock photo restriction** | Stock photos only for **brand-new, unopened** items |
| **What to show** | The main image should clearly show the item sold and must not include accessories or props not included with it |
| **Watermarks prohibited** | No watermarks or seller logos |
| **Text overlays prohibited** | No "Free Postage" or promotional text overlaid on images (this belongs in the title/subtitle/description) |
| **Borders prohibited** | No borders, frames, or extra graphics |
| **Contact information** | No phone numbers, email addresses, URLs, or social accounts in images |

### Common image violations
- Main image with a watermark or store logo
- Promotional text or price overlaid on the image
- A stock photo instead of an actual photo for a used item
- An animated GIF
- Image longest side under 500 pixels

## Description Format

| Rule | Description |
|------|------|
| **Allowed HTML** | Formatting tags: `<b>`, `<br>`, `<p>`, `<ul>`, `<ol>`, `<div>`, `<table>`; `<a href>` links must include `target="_blank"` and be compliant |
| **Image tags** | `<img>` allowed, but assets must load over **HTTPS** |
| **Inline styles** | Inline CSS via `style=""` allowed (color, font, margin, border, and so on) |
| **Active content prohibited** | `<script>`, `<iframe>`, `<video>`, `<form>`, `<input>`, `<embed>`, `<object>`, `<style>` blocks, and Flash |
| **Event attributes prohibited** | Inline event handlers such as `onclick`, `onload`, `onmouseover` |
| **Prohibited behaviors** | Cookie injection, automatic pop-ups, autoplay audio/video, automatic redirects off eBay |
| **Error message** | Violating code triggers "Disallowed JavaScript/HTML Syntax" |

---

## Description Content

| Rule | Description |
|------|------|
| **Off-site links prohibited** | No links to websites outside eBay, **even if not clickable** |
| **Allowed links** | Only other eBay pages, item videos, eBay-approved shipping services, and legally required information; must use HTTPS |
| **Contact information prohibited** | Before a sale, no names, addresses, phone numbers, email addresses, social accounts, external URLs, or payment/banking information in the description |
| **Allowed video sites** | YouTube, Vimeo, Brightcove, Ustream, Screencast, Kizoa, DailyMotion (videos must relate to the item) |
| **Video attribution limits** | Third-party video attribution must not contain external links or contact information; text must not exceed **10 words**; logos must not exceed **88 x 33 pixels**; no flashing, movement, or animation |
| **Store name limit** | A store name must not be a URL or contain ".com", ".net", ".org", or ".edu" |
| **Prohibited content** | No obscene or offensive material; no false or misleading information |

---

## Mobile Description

| Rule | Description |
|------|------|
| **Mobile first** | Most sales happen on mobile, and eBay renders a simplified description |
| **Layout limits** | Multi-column table layouts collapse and misalign on mobile and can affect search ranking |
| **Recommended practice** | Single-column layouts, simple formatting, clear heading hierarchy |
| **Image optimization** | Images inside the description must also be ≤ 7 MB and served over HTTPS |

---

## Listing Compliance Checklist

### Image quantity
- [ ] Total images ≤ 24
- [ ] At least 2, 6 or more recommended
- [ ] Main image clearly shows the item

### Image size and format
- [ ] Longest side ≥ 500 pixels
- [ ] 800–1600 pixels recommended
- [ ] Each image ≤ 7 MB (computer upload)
- [ ] Allowed format such as JPEG/PNG
- [ ] Animated GIF not used

### Photo content
- [ ] Used items use actual photos
- [ ] Main image has no text overlay
- [ ] No watermarks, logos, or borders
- [ ] No promotional text or price
- [ ] No contact information

### Description format
- [ ] No script/iframe/form/embed/style blocks
- [ ] Images and assets load over HTTPS
- [ ] No inline event handlers
- [ ] No autoplay or automatic redirects

### Description content
- [ ] No off-site links
- [ ] No contact information (phone/email/URL/social media)
- [ ] Videos from allowed video sites
- [ ] Description content truthful and accurate

### Mobile
- [ ] Single-column layout
- [ ] Simple formatting with clear hierarchy
