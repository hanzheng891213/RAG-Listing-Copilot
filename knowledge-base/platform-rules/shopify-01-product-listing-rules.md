# Shopify 商品上架与详情页规范 (Product Listing & Detail Page Rules)

## 概述

Shopify 对商品的标题、描述、Handle（URL）、分类、标签、价格与库存字段都有结构性要求。与 Amazon 不同，Shopify 是独立站，平台硬性字段限制较少，更多规则来自搜索引擎展示、销售渠道（Google、Facebook）对接和 Shopify 服务条款。违反上架规范会导致商品被下架、销售渠道被拒、店铺被警告，严重时账户被暂停。

---

## 商品标题 (Product Title)

| 规则 | 说明 |
|------|------|
| **字段上限** | Shopify 帮助文档未给出明确硬性上限；Shopify 生态（CSV 导入、第三方连接器、API 字段）普遍以 **255 个字符**为上限 |
| **推荐长度** | 建议 ≤ 60 字符，以便完整显示在 Google 搜索结果中；移动端展示建议 ≤ 120 字符 |
| **必填与唯一性** | 标题为必填；平台不强制唯一，但应避免站内完全重名 |
| **禁止格式** | 禁止全大写（ALL CAPS）、重复关键词堆砌、过多 Emoji 和特殊符号（!!!、★★★）|
| **禁止内容** | 禁止促销词（"Free Shipping"、"Best Seller"）、价格、联系方式、URL、竞品品牌名 |
| **语言** | 使用目标市场语言，专有名词可保留英文 |

示例：✅ `Ceramic Coffee Mug 350ml - Matte Black, Dishwasher Safe`；❌ `***BEST MUG!!!*** FREE SHIPPING!!!`

## 商品描述 (Product Description)

| 规则 | 说明 |
|------|------|
| **格式** | 使用 Shopify 富文本编辑器（Rich Text Editor），可通过 `<>` 按钮切到 HTML 源码 |
| **字符上限** | Shopify 帮助文档未规定硬性字符上限；部分第三方连接器限制约 **10,000 字符** |
| **推荐篇幅** | 建议 150–400 个英文单词，按 SEO 与转化率经验值 |
| **支持的 HTML 标签** | `<p>` `<br>` `<strong>`/`<b>` `<em>`/`<i>` `<u>` `<a>` `<ul>` `<ol>` `<li>`；顶层元素必须是段落或列表，否则会被清洗 |
| **禁止标签** | 禁止 `<script>`、`<iframe>` 等脚本与嵌入标签，会被系统剥离 |
| **内容要求** | 描述需与商品实际一致，禁止夸大功效、虚假承诺、误导性声明 |
| **图片** | 描述内可嵌入图片，但图片同时会计入商品媒体数量限制 |

最佳实践：首段说明"这是什么、解决什么问题"，用列表呈现规格与包装清单，不要整段照搬供应商文案（重复内容会削弱 SEO）。

## Handle 与 URL 规则 (Handle & URL)

| 规则 | 说明 |
|------|------|
| **字符集** | 仅允许小写字母、数字与连字符 `-`，不允许空格 |
| **自动生成** | 由标题自动生成；空格与特殊字符转为连字符，连续字符合并为一个 `-` |
| **唯一性** | 必须唯一；重名时系统自动追加数字（如 `potion`、`potion-1`）|
| **修改标题不联动** | 商品创建后修改标题**不会**自动更新 Handle，需手动编辑 |
| **长度** | Shopify 未规定官方上限；建议 ≤ 50 字符精简表达 |
| **多语言** | 使用 Markets 时建议为各语言翻译 Handle（如 `/products/robe-ete-bleue`）|

## 商品类型与分类 (Product Type & Category)

| 字段 | 说明 |
|------|------|
| **Product Category（商品分类）** | 从 Shopify 标准商品分类法（Standard Product Taxonomy，约 10,000 个分类、1,000+ 属性，三级层级）中下拉选择，回答"这是什么商品" |
| **未分类风险** | 未选择分类的商品标记为 **Uncategorized**，会降低在销售渠道（Google、Facebook、Shop）的可发现性 |
| **Category Metafields（分类元字段）** | 选定分类后自动解锁对应属性（颜色、材质、尺码等），提升渠道对接与筛选体验 |
| **Product Type（商品类型）** | 商家自定义的自由文本字段，用于内部分组；建议优先使用标准分类 |

---

## 标签与集合 (Tags & Collections)

| 规则 | 说明 |
|------|------|
| **每商品标签上限** | 最多 **250 个标签** |
| **单个标签长度** | 最多 **255 个字符** |
| **推荐标签长度** | 便于管理，建议 ≤ 16 个字符 |
| **推荐字符集** | 仅用普通字母、数字与连字符 `-`；避免重音字符与符号；大小写规则说法不一，建议统一小写 |
| **集合类型** | 手动集合（Manual）与自动集合（Smart/Automated，按标签或条件自动匹配）|
| **标签层级** | 标签仅作用于商品层级，不作用于变体层级 |

---

## 价格与库存字段 (Price & Inventory)

| 规则 | 说明 |
|------|------|
| **Price** | 纯数字，不含货币符号与千分位分隔符 |
| **Compare-at price** | 划线价，须**高于** Price，否则会被判定为无效对比价 |
| **成本价 / 税务** | Cost per item 选填、不前台展示；Charge tax 须与目标市场税务一致 |
| **SKU** | 建议 ≤ 16 字符，同一店铺内应唯一 |
| **Barcode** | 每个变体最多 20 个条码，每条 ≤ 255 字符，支持 UPC/EAN/ISBN/GTIN/ASIN |
| **Inventory / Weight** | 可设置追踪数量与超卖策略；重量影响运费，应填写以确保结账准确 |
| **商品状态** | Active / Draft / Archived；须发布到 Online Store 与对应销售渠道 |

## 通用上架规则与违规后果

| 规则 | 说明 |
|------|------|
| **禁止重复上架** | 不得为同一商品创建多个重复页面（会稀释 SEO）|
| **类目准确性** | 商品必须归入最贴近的标准分类 |
| **销售渠道** | 对接 Google/Facebook 等渠道时，标题、描述、价格、库存需符合各渠道额外规范 |
| **禁止违规内容** | 禁止违禁品、仿冒品、虚假健康声明（详见禁售政策文档）|
| **违规后果** | 字段不规范影响 SEO 与渠道审核；描述虚假夸大导致商品移除与账户警告；仿冒或违禁品将致商品移除、支付冻结，严重时店铺被暂停或终止 |

---

## Listing 合规检查清单

### 标题与描述
- [ ] 标题 ≤ 255 字符（建议 ≤ 60），无全大写/堆砌/促销词
- [ ] 描述使用富文本，未使用 `<script>`/`<iframe>`，非照搬供应商原文
- [ ] 内容与商品实际一致，无虚假/夸大功效

### Handle / URL
- [ ] 仅含小写字母、数字、连字符，唯一且简短（建议 ≤ 50 字符）
- [ ] 多语言市场已翻译 Handle

### 分类
- [ ] 已选择标准 Product Category（非 Uncategorized）并填写关键 Category Metafields

### 标签与集合
- [ ] 标签数 ≤ 250，单个标签 ≤ 255 字符，已加入对应集合

### 价格与库存
- [ ] Price 为纯数字，Compare-at price 高于 Price
- [ ] 已设置 SKU、重量、库存与超卖策略
- [ ] 状态为 Active 并已发布到目标销售渠道
