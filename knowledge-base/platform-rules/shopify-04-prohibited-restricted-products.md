# Shopify 禁售与受限商品政策 (Prohibited & Restricted Products)

## 概述

Shopify 的《可接受使用政策》（Acceptable Use Policy, AUP）作为服务条款的组成部分具有约束力，规定了禁止销售的商品类别与受限商品。违反 AUP（即使是"不知情"）可能导致商品被移除、支付被冻结、店铺被暂停甚至账户被终止。注意：即便某商品不违反 AUP，也可能因 Shopify Payments 或第三方支付渠道的独立禁售清单而被拒绝收款。

---

## AUP 禁止的商品与服务 (Prohibited Products & Services)

| 类别 | 说明 |
|------|------|
| **仿冒品** | 销售假货，或未经授权使用他人知识产权、侵犯知识产权 |
| **违法商品** | 在经营地违法的任何商品或服务 |
| **受管制/非法药物** | 管制物质、非法药物及无资质销售的相关产品 |
| **未验证的补充剂** | 不符合适用法规的补充剂或健康产品 |
| **虚假健康/医疗声明** | 作出虚假声明的健康或医疗产品；需处方但无有效处方流程的药品 |
| **被召回商品** | 已受政府召回（recall）的产品 |
| **武器与枪械** | 武器、枪械及相关配件（未满足法律合规要求时）|
| **自残相关** | 促进或鼓励故意自残的产品与内容 |
| **仇恨内容** | 宣扬仇恨、暴力或歧视的内容 |
| **非法活动工具** | 用于协助违法活动的产品或服务 |
| **无年龄验证的受限品** | 未做合规年龄验证的成人/年龄限制商品 |

> 该清单并非穷尽列举，且会因国家/地区而异。新增商品类目前应先核对 AUP 与当地法规。

## 受限商品 (Restricted Products)

受限商品并非绝对禁止，但需满足额外合规条件。

| 类别 | 合规要求 |
|------|---------|
| **补充剂 / 保健品** | 需符合目标市场法规（如欧盟、ANVISA 等），仅可用授权健康声明，需附免责声明 |
| **医疗器械** | 需相应认证与资质 |
| **电子烟 / 烟草** | 多数地区受限或需许可，部分市场禁售 |
| **酒类** | 需满足当地许可与年龄验证要求 |
| **成人用品** | 需年龄验证与内容合规 |
| **处方药 / 药品** | 需有效处方流程与相应许可 |
| **兽药 / 农资** | 需符合行业监管要求 |

### 补充剂与健康声明的红线
- ❌ 禁止：疾病相关的"治愈/治疗/预防"表述（如 "treats eczema"、"cures arthritis"）
- ❌ 禁止：未经证实的功效承诺、绝对化表述（"100% 有效"、"永久根治"）
- ✅ 允许：结构/功能类表述（如 "supports healthy skin"、"may help joint comfort"），并附合规免责声明
- ✅ 建议：为每个 SKU 建立"声明库"，记录可用措辞、禁用措辞与必要限定语

## 知识产权与仿冒品 (Intellectual Property & Counterfeit)

| 规则 | 说明 |
|------|------|
| **禁止仿冒** | 不得销售仿冒品或侵犯他人商标、版权、专利的商品 |
| **授权要求** | 使用品牌 Logo、角色形象、图案须持有合法授权 |
| **图片版权** | 不得盗用他人产品图、模特图、品牌素材 |
| **高风险做法** | "同款""平替"等暗示性描述在有品牌元素时风险显著升高 |
| **监控机制** | 主要品牌会主动监控 Shopify 店铺；一次 DMCA 投诉即可触发账户审查 |
| **后果** | 商品移除、店铺暂停或终止，且可能面临法律责任 |

## 支付渠道的独立限制 (Payment Processor Restrictions)

| 要点 | 说明 |
|------|------|
| **Shopify Payments 独立清单** | Shopify Payments 有自己的禁售企业与产品清单（含仿冒品、伪药品），且按国家/地区不同 |
| **第三方渠道** | Stripe 等第三方渠道标准通常比当地法律更严格，尤其针对暗示性健康声明 |
| **实际影响** | 商品可能合法却不被支付渠道接受，导致无法收款；可考虑更换网关，但各渠道均有各自排除项 |
| **伪药品风险** | 带暗示性健康声明的补充剂与化妆品常被划为"伪药品"（pseudo-pharmaceuticals）而受限 |

## 上架前合规检查清单

- [ ] 该商品是否属于 AUP 明令禁止的类别？
- [ ] 是否涉及品牌元素、角色形象、他人图片（需授权）？
- [ ] 是否属于受限类别（补充剂、医疗、酒类、烟类、成人等）？
- [ ] 是否已核对目标市场的法律法规与许可要求？
- [ ] 是否涉及健康声明？是否仅使用授权措辞？是否附免责声明？
- [ ] 商品是否曾被政府召回？
- [ ] 是否已确认该商品被 Shopify Payments 接受？
- [ ] 描述、图片、评论、FAQ、广告文案是否全部合规（非仅商品页）？

## 违规后果与处理流程

| 处理层级 | 具体措施 |
|---------|---------|
| **第一层（默认）** | 通知商家、给予自行整改机会，通常**先在产品层级**处置 |
| **第二层** | 要求移除违规内容、移除违规商品、阻止收款或资金转移 |
| **第三层** | 临时限制后台访问、锁定店铺 |
| **最严重** | 账户终止（违反服务条款可能导致**立即终止**）|

- Shopify 声明其执法取向为：先通知、给予自我整改机会、默认在产品层级执法、账户层级处置为最后手段。
- 对于仿冒品与严重违规，可能直接跳过缓冲层级。
- 账户被限制或终止后，Shopify 会通过邮件或后台通知并提供**申诉**入口，申诉由人工团队审核。
- 高拒付率（chargeback）、支付欺诈指标异常也是店铺被暂停的常见原因，与商品合规同等重要。
