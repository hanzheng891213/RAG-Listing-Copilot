# eBay 图片与描述规范 (eBay Images and Description Rules)

## 概述

图片是 eBay 买家决策的首要因素，描述则承载完整商品信息。本文件（基于 eBay US 站点）说明免费图片数量、尺寸与格式要求、照片禁用内容，以及描述中允许的 HTML 与禁止的活动内容 (Active Content)、外部链接和联系方式。图片带水印可能导致 Listing 不出现在搜索结果中，描述含违规内容会被隐藏或移除，重复违规将限制销售权限。

---

## 图片数量与费用 (Image Quantity)

| 规则 | 说明 |
|------|------|
| **免费数量** | 每条 Listing 最多可免费添加 **24 张**图片（1 张主图 + 23 张附图），部分类目除外 |
| **终端支持** | 桌面端、移动端与 eBay App 均支持 24 张免费图 |
| **建议数量** | 至少 2 张，建议 6 张以上；3 张以上图片可明显提升转化率 |
| **主图** | 第 1 张为主图 (Gallery Image)，展示在搜索结果中 |

---

## 图片尺寸与格式 (Image Size and Format)

| 规则 | 说明 |
|------|------|
| **最小尺寸** | 最长边至少 **500 像素**，低于此值将被拒绝 |
| **推荐尺寸** | **800–1600 像素**；**1600 像素**可获得最佳缩放 (Zoom) 体验，便于移动端查看细节 |
| **缩放功能** | Zoom 一般要求最长边至少 **800 像素**（部分类目门槛更高，建议直接使用 1600px）|
| **文件大小** | 从电脑上传每张 ≤ **7 MB**；从网址抓取 ≤ **12 MB** |
| **格式** | JPEG、PNG、GIF、TIFF、BMP、WEBP、HEIC、AVIF；**JPEG 最推荐**（体积小、质量高）|
| **色深/格式限制** | 不支持动画 GIF |

---

## 照片内容要求 (Photo Requirements)

| 规则 | 说明 |
|------|------|
| **背景** | 推荐**纯白或中性背景**；反光类商品（如珠宝）可用黑色背景突出质感 |
| **实拍要求** | 二手/使用过的商品**必须使用实物照片** |
| **库存图限制** | 库存图 (Stock Photo) 仅可用于**全新未拆封**商品 |
| **展示内容** | 主图应清晰展示所售商品，不得包含不随商品附赠的配件或道具 |
| **禁止水印** | 禁止水印、卖家 Logo |
| **禁止文字叠加** | 禁止在图上叠加 "Free Postage"、促销文字等（此类信息应放入标题/副标题/描述）|
| **禁止边框** | 禁止添加边框、相框或额外图形 |
| **联系方式** | 禁止在图片中出现电话、邮箱、网址、社交账号 |

### 常见图片违规
- 主图带水印或店铺 Logo
- 图片上叠加促销文字或价格
- 用库存图代替二手商品实物图
- 使用动画 GIF
- 图片最长边不足 500 像素

## 描述格式 (Description Format)

| 规则 | 说明 |
|------|------|
| **允许的 HTML** | 格式化标签：`<b>`、`<br>`、`<p>`、`<ul>`、`<ol>`、`<div>`、`<table>`；链接 `<a href>` 须带 `target="_blank"` 且合规 |
| **图片标签** | `<img>` 可用，但资源必须通过 **HTTPS** 加载 |
| **内联样式** | `style=""` 内联 CSS 可用（颜色、字体、边距、边框等）|
| **禁止活动内容** | 禁止 `<script>`、`<iframe>`、`<video>`、`<form>`、`<input>`、`<embed>`、`<object>`、`<style>` 块及 Flash |
| **禁止事件属性** | 禁止 `onclick`、`onload`、`onmouseover` 等内联事件处理器 |
| **禁止行为** | 禁止 Cookie 植入、自动弹窗、自动播放音视频、自动跳转站外 |
| **报错提示** | 含违规代码时会提示 "Disallowed JavaScript/HTML Syntax" |

## 描述内容规范 (Description Content)

| 规则 | 说明 |
|------|------|
| **禁止站外链接** | 不得包含指向 eBay 以外网站的链接，**即使不可点击**也禁止 |
| **允许的链接** | 仅限：其他 eBay 页面、商品视频、eBay 认可的货运服务、法律要求信息；且须为 HTTPS |
| **禁止联系方式** | 成交前禁止在描述中提供姓名、地址、电话、邮箱、社交账号、外部网址、支付/银行信息 |
| **允许的视频站点** | YouTube、Vimeo、Brightcove、Ustream、Screencast、Kizoa、DailyMotion（视频须与商品相关）|
| **视频署名限制** | 第三方视频署名不得含外链或联系方式，文字不超过 **10 个词**，Logo 不超过 **88 x 33 像素**，不得闪烁/移动/动画 |
| **店铺名限制** | 店铺名不得为网址或含 ".com"、".net"、".org"、".edu" |
| **禁止内容** | 无淫秽/冒犯性材料、无虚假或误导信息 |

## 移动端描述规范 (Mobile Description)

| 规则 | 说明 |
|------|------|
| **移动优先** | 大多数成交发生在移动端，eBay 会渲染简化版描述 |
| **布局限制** | 多列表格布局在移动端会塌陷错位，可能影响搜索排名 |
| **建议做法** | 使用单列布局、简洁排版、清晰的标题层级 |
| **图片优化** | 描述内图片同样需 ≤ 7 MB 且使用 HTTPS |

## Listing 合规检查清单

### 图片数量
- [ ] 图片总数 ≤ 24 张
- [ ] 至少 2 张，建议 6 张以上
- [ ] 主图清晰展示商品

### 图片尺寸与格式
- [ ] 最长边 ≥ 500 像素
- [ ] 推荐 800–1600 像素
- [ ] 单张 ≤ 7 MB（电脑上传）
- [ ] 使用 JPEG/PNG 等允许格式
- [ ] 未使用动画 GIF

### 照片内容
- [ ] 二手商品使用实物照片
- [ ] 主图无文字叠加
- [ ] 无水印、Logo、边框
- [ ] 无促销文字与价格
- [ ] 无联系方式

### 描述格式
- [ ] 未使用 script/iframe/form/embed/style 块
- [ ] 图片与资源通过 HTTPS 加载
- [ ] 未使用内联事件处理器
- [ ] 无自动播放或自动跳转

### 描述内容
- [ ] 无站外链接
- [ ] 无联系方式（电话/邮箱/网址/社交账号）
- [ ] 视频来自允许的视频站点
- [ ] 描述内容真实准确

### 移动端
- [ ] 使用单列布局
- [ ] 排版简洁、层级清晰
