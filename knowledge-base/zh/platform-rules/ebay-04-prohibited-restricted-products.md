# eBay 禁售与受限商品政策 (eBay Prohibited and Restricted Products)

## 概述

eBay 出于法律合规与平台安全，将商品分为**禁止刊登**、**受限刊登**和**可能侵犯知识产权**三类，且清单并非穷尽。本文件（基于 eBay US 站点，跨境销售还须同时满足买家所在国法律）说明禁售/受限类别、仿冒品与 VeRO 知识产权规则、危险品要求及上架前合规检查。违规将导致 Listing 移除、费用没收，重复违规会被限制销售权限甚至永久停用账户，严重者还可能承担法律责任。

---

## 禁止刊登商品 (Prohibited Items)

以下商品**不得刊登**（示例，非完整清单）：

| 类别 | 说明 |
|------|------|
| **毒品与吸毒用具** | 违禁药物、处方药、制毒教程类内容 |
| **武器弹药** | 枪支、弹药、刀具及仿制/玩具枪、催泪喷雾、电击器 |
| **人体器官与遗骸** | 人体部位、遗骸 |
| **被召回商品** | 已召回或存在安全隐患的产品 |
| **赃物** | 被盗物品、被抹除序列号的物品 |
| **侵权/违规电子产品** | 有线电视解密器、雷达扫描器、交通信号控制设备、窃听/监听设备 |
| **冒犯性材料** | 种族/民族歧视材料、纳粹纪念品 |
| **禁运国商品** | 来自受制裁/禁运国家（如古巴）的商品 |
| **鼓励违法内容** | 描述违法方法的书籍/电子书 |

## 受限刊登商品 (Restricted Items)

以下商品**仅在满足特定条件时**可刊登：

| 类别 | 限制条件示例 |
|------|------------|
| **酒精与葡萄酒** | 须持有相应许可证，且遵守目的地法律 |
| **烟草与电子烟** | 严格限制，多数站点禁止或需资质 |
| **成人用品** | 须归入成人专属类目，不得出现在一般搜索中 |
| **处方药与医疗器械** | 隐形眼镜、心脏起搏器、手术器械等受限 |
| **农药** | 须符合当地登记法规 |
| **植物与种子** | 受农业检疫与进口法规限制 |
| **货币与贵金属** | 纸币、硬币、礼品卡、信用卡受限 |
| **门票与证券** | 活动门票、股票证券、虚拟货币受限 |
| **房地产** | 须使用专门类目与格式 |
| **战争/军事物品** | 军用物品、政府与运输相关物品受限 |
| **监控设备** | 电子监控、窃听设备受限 |

> 提示：受限商品的具体条件随站点与当地法律变化，刊登前必须查阅 eBay 对应站点的完整政策页。

## 仿冒品与知识产权 (Counterfeit & Intellectual Property)

| 规则 | 说明 |
|------|------|
| **禁止仿冒品** | 禁止销售仿冒品、复制品 (replica)、赝品及侵权商品 |
| **VeRO 计划** | 知识产权权利人可通过 Verified Rights Owner 计划举报侵权 Listing |
| **举报后果** | 被举报 Listing 会被移除，卖家收到通知及权利人联系方式 |
| **拥有正品≠可随意使用商标** | 即使商品为正品，若 Listing 误用商标/图片，权利人仍可投诉 |
| **禁止重新刊登** | 问题未解决前不得重新刊登被移除商品 |
| **申诉途径** | 联系权利人提供授权/正品证明（发票、许可、品牌协议），或等待权利人回复后联系 eBay |
| **合规来源** | 保留进货发票与授权文件，核实供应商资质 |
| **使用原创素材** | 使用自拍图片、自行撰写描述，避免未授权商标与 Logo |

> VeRO 仅适用于真正的知识产权侵权，不适用于最低广告价 (MAP)、选择性分销或转售限制等商业纠纷。

## 危险品与受管制物品 (Dangerous Goods)

| 类别 | 说明 |
|------|------|
| **电池** | 锂电池、含电池产品有运输与刊登限制 |
| **烟火与爆炸物** | 烟花、爆竹等 |
| **制冷剂** | 如 Freon 等受管制化学品 |
| **易燃/腐蚀性物质** | 危险化学品、压缩气体 |
| **受管制材料** | 危险、受限或受监管材料，eBay 可能基于自身判断额外限制 |
| **跨境限制** | 在卖家所在国合法的商品，在买家所在国可能违法，须同时核查进口法规 |

## 上架前合规检查清单

- [ ] 确认商品不在禁止刊登清单中
- [ ] 若为受限商品，确认已满足全部条件（许可证、类目、目的地法律）
- [ ] 确认商品非仿冒品、复制品或侵权商品
- [ ] 核实供应商资质并保留进货发票
- [ ] 核查是否涉及商标、版权、专利或外观设计权
- [ ] 检查商品是否属于危险品/受管制物品
- [ ] 确认跨境销售的进口与运输合规
- [ ] 确认支付服务（如信用卡网络）规则允许该交易
- [ ] 登录 eBay 对应站点查阅最新完整政策页

---

## 违规后果

| 违规类型 | 处罚 |
|---------|------|
| 轻度（信息不完整）| Listing 被隐藏，修正并审核后恢复 |
| 中度（刊登受限商品/含违规内容）| Listing 移除 + 警告 + 费用没收 |
| 知识产权侵权 (VeRO) | Listing 移除、丧失买家/卖家保护、搜索排名下降、反馈移除 |
| 重复侵权 | 临时限制销售（7 天/30 天），进而永久停用 |
| 严重违规 | 账户停用、永久移除销售权限、扣押资金、法律责任 |

## Listing 合规检查清单

### 禁止刊登商品
- [ ] 商品不属于毒品、武器、赃物、禁运品等禁售类别
- [ ] 商品未被召回
- [ ] 商品不含被抹除的序列号

### 受限商品
- [ ] 已确认商品属于受限类别并满足其条件
- [ ] 已归入正确的专属类目
- [ ] 已核查买家所在国法律

### 知识产权
- [ ] 商品非仿冒品或复制品
- [ ] 未在 Listing 中误用他人商标或图片
- [ ] 已保留正品进货凭证
- [ ] 被移除商品未擅自重新刊登

### 危险品
- [ ] 电池/化学品等已确认可刊登
- [ ] 已确认运输方式合规
- [ ] 已核查跨境进口限制

### 上架前流程
- [ ] 已查阅 eBay 对应站点最新政策
- [ ] 已确认支付服务规则允许
- [ ] 已建立违规应对与申诉流程
