# eBay 标题、副标题与物品属性 (eBay Title, Subtitle and Item Specifics)

## 概述

标题是 eBay 搜索算法 Cassini 排序与买家点击的核心，物品属性 (Item Specifics) 决定 Listing 能否被类目筛选命中及使用目录 (Catalog)。本文件（基于 eBay US 站点）说明标题 80 字符上限与禁用内容、副标题 55 字符限制、物品属性必填要求及品牌/MPN/GTIN 规则。标题或属性不符会导致 Listing 被隐藏或移除，属性造假还可能引发"与描述不符"纠纷和账户处罚。

---

## 标题要求 (Title Requirements)

| 规则 | 说明 |
|------|------|
| **最大长度** | **80 个字符**（含空格与所有标点）；超出时刊登表单直接报错 |
| **建议长度** | 使用 75–80 字符以获取最大曝光；低于 60 字符通常浪费曝光位 |
| **显示截断** | 移动端搜索约显示前 50–55 字符，桌面端约 65–70 字符，**核心关键词须前置** |
| **纯文本** | 禁止 HTML 标签 |
| **大小写** | 禁止全大写 (ALL CAPS) |
| **特殊字符** | 禁止下标/上标及 ♥、™、½、° 等符号，须替换为可搜索的词 |
| **禁止促销词** | 禁止 "WOW"、"L@@K"、"GREAT DEAL"、"MUST SEE"、"Free Shipping" 等 |
| **禁止堆砌** | 不得重复同一词、不得堆叠多个品牌名 |
| **禁止信息** | 不得含店铺名、用户名、URL、联系方式 |
| **准确性** | 不得有拼写错误，不得含虚假或误导信息 |

### 标题示例
- ✅ 正确：`Apple iPhone 15 Pro Max 256GB Natural Titanium Unlocked New`
- ❌ 错误：`***HOT*** iPhone 15 Pro Max!!! L@@K FREE SHIPPING BEST DEAL!!!`

### 推荐结构
品牌 + 产品名称 + 型号/尺寸 + 核心特性 + 成色（如 `Vintage Pyrex Butterprint Mixing Bowl 443 Blue White 1 1/2 Qt`）

## 副标题 (Subtitle)

| 规则 | 说明 |
|------|------|
| **最大长度** | **55 个字符**（含空格与标点），超出无法保存 |
| **费用** | **付费可选升级项**，费率随刊登形式、商品价格与类目变化，以刊登表单显示为准 |
| **索引** | 副标题文字**不被 Cassini 搜索索引**，仅作为提升点击率的展示文案 |
| **内容** | 可补充卖点、配件、成色、规格；须与商品 100% 相符 |
| **禁止内容** | 同标题：无促销词、无联系方式、无外链、无特殊符号 |
| **字符注意** | `&` 在某些工具中按 5 个字符计算 |

> 提示：关键词应全部放入主标题，副标题仅作补充展示。

## 物品属性 (Item Specifics)

| 规则 | 说明 |
|------|------|
| **字段分级** | 每个类目约 5–30+ 个字段，分为 **Required（必填）**、**Recommended（推荐）**、**Optional（可选）** |
| **必填强制** | 必填属性缺失时 eBay **拒绝刊登或修改** |
| **准确性** | 必填属性须准确完整，不得填写错误字段（如把品牌填进尺寸） |
| **禁止占位** | 若制造商已提供信息，禁止用 "Does not apply"、"N/A"、"Unbranded"、generic 等占位 |
| **成色一致** | 所选成色须与标题、描述、属性一致 |
| **类目变化** | 类目必填项会随时间调整，长期在架 Listing 可能变为不合规 |
| **作用** | 属性用于买家筛选与目录匹配，不完整会降低搜索曝光 |

## 品牌 / MPN / GTIN 要求 (Product Identifiers)

在 **Product Identifier Mandate** 下，若类目要求品牌/MPN/GTIN 而未填写，商品**无法刊登或更新**。可用 `GetCategoryFeatures` 判断类目是否强制。

| 标识 | 规则 |
|------|------|
| **Brand（品牌）** | 须为真实品牌名（如 Apple、Nike）。禁止占位词（"Brand new"、"Made in China"、"See description"）、纯特殊字符、单个字母；确实无品牌可填 **Unbranded** |
| **MPN（制造商零件号）** | 由字母和数字组成，须唯一定位该零件；不得填 GTIN、标题或品牌名；不得为纯符号或 "see desc"、"compatible" 等无效值 |
| **GTIN（EAN/UPC/ISBN/JAN）** | UPC 为 **12 位**，EAN 通常 **13 位**（少数 8 或 14 位），ISBN 须符合 ISBN-10/13，JAN 为 **13 位**；须放入指定字段，不得自造 |
| **无标识时** | 无 MPN/GTIN 可填 **"Does not apply"**（具体可接受文案随站点不同）|
| **品牌型号匹配** | 品牌与型号须对应（ZTE 手机不得标为 iPhone 6）|
| **变体要求** | 变体 Listing 中不同变体**不得复用同一 GTIN**；GTIN 应指定在变体层级，Brand 在商品层级 |

## 类目与目录 (Category & Catalog)

| 规则 | 说明 |
|------|------|
| **正确归类** | 商品必须归入正确的浏览树类目 |
| **强制目录类目** | 部分类目有匹配商品时**必须使用 eBay Catalog**（如手机 9355、数码相机 31388、电视 3320、GPS 156955 等）|
| **ePID** | eBay 产品标识符，类似 ASIN，优先于 GTIN 用于目录匹配 |
| **目录收益** | 匹配目录可自动填充标题、描述、属性与库存图 |
| **目录未匹配后果** | 曝光受限，甚至 Listing 被移除 |
| **描述不可替代** | 目录信息不替代卖家自己的商品描述，卖家仍对内容负责 |

## 关键词与搜索优化 (Search Optimization)

| 规则 | 说明 |
|------|------|
| **Cassini 权重** | 前 **5–7 个词**权重最高，优先精确短语匹配 |
| **相关性** | 所有词必须与所售商品直接相关 |
| **禁止对比词** | 禁止 "shirt not pants"、"like Chanel"、"not Supreme"（免责声明等同于主张）|
| **兼容表述** | 配件须用 "fits"、"for"、"compatible with" 置于品牌/型号**之前**；珠宝、服装、配饰类不得置于品牌名之前 |
| **禁止行为** | 不得用问号关键词（如 "antique?"）、隐藏文字、下拉框操纵搜索 |
| **同义词** | 可自然加入同义词（如 "laptop / notebook"）以扩大命中 |

## Listing 合规检查清单

### 标题
- [ ] 长度 ≤ 80 字符
- [ ] 关键信息位于前 50 字符
- [ ] 无全大写
- [ ] 无特殊符号（♥ ™ ½ °）
- [ ] 无促销词（WOW / L@@K / Free Shipping）
- [ ] 无重复词、无品牌堆叠
- [ ] 无店铺名、用户名、URL

### 副标题
- [ ] 长度 ≤ 55 字符
- [ ] 内容与商品相符
- [ ] 无促销词与联系方式

### 物品属性
- [ ] 所有 Required 字段已填
- [ ] 填写值准确、非占位词
- [ ] 成色与标题/描述一致
- [ ] 属性填在正确字段

### 品牌 / MPN / GTIN
- [ ] Brand 为真实品牌或 Unbranded
- [ ] MPN 为字母数字组合且唯一
- [ ] GTIN 位数正确（UPC 12 / EAN 13）
- [ ] 变体间未复用 GTIN

### 类目与关键词
- [ ] 归入正确类目
- [ ] 强制目录类目已使用 Catalog
- [ ] 无对比词与免责声明
- [ ] 兼容表述用 for/fits 前置
