# 家居厨房上架模板 (Home & Kitchen Listing Template)

## 概述

家居厨房 Listing 的核心打法是「尺寸与材质打消顾虑」：买家最担心买回去放不下、材质不安全、不好清洗。标题要写清产品类型、材质、容量/尺寸；五点必须给出真实测量值（含单位）、具体材质、清洁保养方式与使用场景。本文档提供可套用的结构，规则边界以 `platform-rules/` 下的规范文档为准。

---

## 适用类目

| 大类目 | 典型子类目 |
|--------|-----------|
| Kitchen & Dining | 餐具、厨具、保鲜盒、水杯、刀具 |
| Home Décor | 装饰摆件、相框、香薰、墙面装饰 |
| Bedding | 床品四件套、抱枕、毯子 |
| Bath | 毛巾、浴帘、浴室收纳 |
| Storage & Organization | 收纳箱、衣柜整理、置物架 |
| Furniture | 小家具、桌面收纳 |
| Appliances | 小家电（需 UL/ETL）、照明 |

> 提示：接触食品的材质需符合食品接触法规，小家电需 UL/ETL 报告，详见产品安全与合规认证文档。

---

## 标题写法 (Title Formula)

**公式**：`品牌 + 产品类型 + 材质 + 容量/尺寸 + 数量/颜色 + 关键特性`

| 要点 | 写法 |
|------|------|
| 前置产品类型 | 前 80 字符内点明是什么（移动端截断窗口）|
| 材质具体化 | 写 "Ceramic"、"Stainless Steel"、"Cotton" 等，禁止只写 "Premium" |
| 尺寸带单位 | 阿拉伯数字 + 单位（12 oz、10 Inch、3 Qt）|
| 禁止 | 全大写、促销语、`!` `*` `$`、"eco-friendly" 等禁词 |

✅ 正例：
- `LumiHome Ceramic Coffee Mug Set - 12 oz, Set of 4, Dishwasher and Microwave Safe, Matte Glaze, White`
- `OakLeaf Stainless Steel Mixing Bowl Set - 3 Pieces, 1.5/3/5 Qt, Non-Slip Base, Nesting Design`
- `CozyNest Cotton Throw Blanket - 50 x 60 Inch, Waffle Weave, Machine Washable, Grey`

❌ 反例：`LumiHome BEST Mugs!!! Eco-Friendly Premium Quality Free Shipping Buy Now`

## 五点描述结构 (Bullet Points Structure)

固定五条角度，每条 ≤ 500 字符，首字母大写，无句末标点与促销语。

| 条 | 固定角度 | 示例（可直接套用） |
|----|---------|-------------------|
| 1 | 使用场景与目标用户 | `EVERYDAY MORNING COFFEE - 12 oz capacity suits a latte or americano, and the tapered rim fits most drip brewers` |
| 2 | 材质与做工 | `FIRED CERAMIC BODY - Fired at high temperature for a chip-resistant glaze that will not absorb odors or stains` |
| 3 | 尺寸/容量与适配 | `TRUE MEASUREMENTS - 3.5 Inch diameter, 4 Inch height; each mug holds 12 oz and stacks in standard cabinets` |
| 4 | 清洁保养与耐用性 | `DISHWASHER AND MICROWAVE SAFE - Top-rack dishwasher safe and microwave safe; hand wash to keep the matte glaze bright` |
| 5 | 包装清单与使用提示 | `SET OF 4 - Four 12 oz mugs in protective foam; wash before first use; not intended for oven or open flame` |

> 尺寸条（第 3 条）是家居厨房最关键的一条：必须写真实测量值，不能只写 "large" 或 "standard size"。

## 产品描述结构 (Description Structure)

≤ 2000 字符，仅可用 `<br>` 换行，无外链、无促销。四段骨架：

1. **场景开场**：产品融入日常的场景（早餐、收纳、待客）
2. **材质与工艺**：具体材质、表面处理、耐用性说明
3. **尺寸与适配**：完整尺寸（含容量/重量）、适配空间、是否可叠放
4. **清洁保养**：清洗方式、使用限制（如不可明火、不可冷冻）

**A+ 内容模块建议**：

| 模块 | 用途 |
|------|------|
| 尺寸信息图 | 标注长宽高与容量，解决"放得下吗" |
| 材质特写组 | 釉面、木纹、织物纹理近距离展示 |
| 清洁保养图 | 洗碗机/微波炉标识与保养步骤 |
| 场景图组 | 厨房、餐桌、客厅三类场景 |
| 对比表 | 对比同系列容量与颜色 |

## 关键词布局 (Keyword Placement)

| 位置 | 该放什么 | 不该放什么 |
|------|---------|-----------|
| 标题 | 品牌 + 品类词 + 材质词 + 尺寸/容量词 | 禁词（eco-friendly、antibacterial）、促销语 |
| 五点（前 2 条权重最高）| 场景词、材质词、容量/尺寸长尾，自然嵌入 | 与产品无关的节日或热点词 |
| 描述 | 使用场景、保养问答长尾（"is it dishwasher safe"）| 关键词堆砌 |
| 后台 Search Terms | 同义词、材质变体、用途补充词，≤ 250 字节，空格分隔 | 品牌名、ASIN、标题已用词 |

## 该品类常见错误

| 错误 | 后果 |
|------|------|
| 尺寸含糊（"large"、"standard size"）| 尺寸不符导致退货与差评 |
| 材质只写 "high quality"，无具体材质 | 买家无法判断，转化低 |
| 未写清洁保养方式 | 差评集中于"难以清洗" |
| 使用 "antibacterial" / "eco-friendly" / "bamboo" 等禁词 | Listing 被抑制 |
| 套件内容不清（未说明不含哪些配件）| 退货率上升 |
| 写未经证实的官方批准/认证声明 | 合规风险，可能下架 |

## 上架检查清单

### 标题
- [ ] ≤ 200 字符，前 80 字符点明产品类型
- [ ] 含具体材质与尺寸/容量
- [ ] 无禁词、无促销语、无全大写

### 五点描述
- [ ] 恰好 5 条，每条 ≤ 500 字符
- [ ] 覆盖场景 / 材质 / 尺寸 / 保养 / 清单五个角度
- [ ] 尺寸为真实测量值并带单位
- [ ] 无定价、配送、联系方式、评论征集

### 描述
- [ ] ≤ 2000 字符，仅 `<br>` 换行
- [ ] 含完整尺寸、适配与保养说明
- [ ] 无外链、无促销

### 关键词
- [ ] 后台 Search Terms ≤ 250 字节
- [ ] 未重复标题词，无品牌与 ASIN

### 图片与 A+
- [ ] 主图纯白底、≥ 1000×1000 px
- [ ] 含尺寸图、材质图、保养图
- [ ] A+ 无价格、无保证/保修声明、无链接
