# 电子产品上架模板 (Electronics Listing Template)

## 概述

电子产品 Listing 的核心打法是「参数驱动决策」：买家在点击前已用规格筛选，因此标题必须前置关键数字（功率、续航、容量、接口），五点描述要用「规格 + 场景 + 兼容性」回答购买顾虑。本文档提供可直接套用的结构与示例文案，规则边界以 `platform-rules/` 下的规范文档为准。建议写作顺序：先确定核心规格与兼容清单，再写标题，最后铺关键词。

---

## 适用类目

| 大类目 | 典型子类目 |
|--------|-----------|
| Electronics | 耳机、音箱、充电器、数据线、移动电源 |
| Computers & Accessories | 键盘、鼠标、扩展坞、USB Hub |
| Cell Phones & Accessories | 手机壳、车载支架、无线充电板 |
| Camera & Photo | 三脚架、补光灯、存储卡 |
| Home Audio & Video | 投影仪、Soundbar、流媒体设备 |

> 提示：含无线功能（Wi-Fi / 蓝牙）的产品需准备 FCC-ID，插电类需 UL/ETL 报告，详见产品安全与合规认证文档。

## 标题写法 (Title Formula)

**公式**：`品牌 + 型号/系列 + 产品类型 + 核心规格 ×2~3 + 兼容性/关键特性 + 颜色或数量`

| 要点 | 写法 |
|------|------|
| 前置核心数字 | 把续航、功率、容量等硬指标放在前 80 字符内（移动端截断窗口）|
| 兼容性明确 | 写具体机型/系统，而非 "universal" 或 "most devices" |
| 长度控制 | ≤ 200 字符，建议 120-160；同一关键词不重复超过 2 次 |
| 禁止 | 全大写、`!` `*` `$`、促销语、时效语（"2026 NEW"）、竞品品牌名 |

✅ 正例：
- `AuroraSound XP200 Bluetooth Speaker - IPX7 Waterproof, 24H Playtime, 30W Stereo, USB-C, Black`
- `VoltEdge 65W USB-C Charger - GaN III, 2-Port PD 3.0, Foldable Plug, for Laptops and Phones`
- `NovaTech A7 Wireless Headphones - 40H Battery, Active Noise Cancelling, Bluetooth 5.3, Over-Ear`

❌ 反例：`AuroraSound Best Waterproof Speaker!!! 2026 NEW #1 Bluetooth Speaker Free Shipping`

## 五点描述结构 (Bullet Points Structure)

固定五条角度，顺序不要随意调换。每条 ≤ 500 字符，首字母大写，无句末标点与促销语。

| 条 | 固定角度 | 示例（可直接套用） |
|----|---------|-------------------|
| 1 | 核心性能与目标用户 | `40 HOURS OF PLAYTIME - A single charge covers a week of commutes and recharges fully in 2 hours via USB-C` |
| 2 | 关键硬件规格 | `DUAL 15 W DRIVERS - Two full-range drivers deliver 30 W stereo output with bass down to 60 Hz` |
| 3 | 兼容性与连接 | `WIDE COMPATIBILITY - Bluetooth 5.3 pairs with iOS, Android, Windows and macOS; 3.5 mm AUX input included` |
| 4 | 防护、认证与做工 | `IPX7 WATERPROOF AND CERTIFIED - Sealed housing survives 30-minute submersion; FCC and CE certified` |
| 5 | 包装清单与使用提示 | `WHAT YOU GET - Speaker, USB-C cable, AUX cable and quick-start guide; charge fully before first use` |

> 写作顺序建议：先写第 2、3 条（规格与兼容），再回填第 1 条，最后收尾第 5 条。

## 产品描述结构 (Description Structure)

≤ 2000 字符，仅可用 `<br>` 换行，无外链、无促销。四段骨架：

1. **场景开场**：谁在什么场景下使用，解决什么问题（2-3 句）
2. **技术展开**：对应五点的规格细节，补充参数表无法承载的说明（如音频编解码、充电协议）
3. **兼容与适配**：明确支持与不支持的系统/机型，降低退货
4. **包装与使用**：清单、首次使用、日常维护

**A+ 内容模块建议**（品牌注册卖家适用）：

| 模块 | 用途 |
|------|------|
| 技术规格对比表 | 对比同系列型号，辅助选择 |
| 兼容性图表 | 列出支持的机型/系统 |
| 场景图组 | 通勤、办公、户外三类场景 |
| 品牌故事 | 建立信任，不含价格与促销 |

## 关键词布局 (Keyword Placement)

| 位置 | 该放什么 | 不该放什么 |
|------|---------|-----------|
| 标题 | 品牌 + 核心品类词 + 2~3 个高搜索量规格词 | 竞品品牌、堆砌的兼容机型名 |
| 五点（前 2 条权重最高）| 长尾词、规格词、场景词，自然嵌入前 100 字符 | 与产品无关的热搜词 |
| 描述 | 使用场景词、问答式长尾（"how to pair"）| 关键词堆砌 |
| 后台 Search Terms | 同义词、缩写、拼写变体、材质/场景补充词，≤ 250 字节，空格分隔 | 品牌名、ASIN、标题已用词 |

## 图片与 A+ 内容建议

| 图位 | 建议内容 |
|------|---------|
| 主图 | 纯白底，产品占画面 ≥ 85%，无文字水印 |
| 第 2 图 | 规格信息图（续航 / 功率 / 接口）|
| 第 3 图 | 兼容性图（列出支持设备）|

| 第 5 图 | 包装清单图（明确标注附带与不附带物品）|
| 第 6 图 | 尺寸比例图 |

## 该品类常见错误

| 错误 | 后果 |
|------|------|
| 标题堆砌兼容品牌（Apple Samsung Sony…）| 判定关键词堆砌或商标侵权 |
| 兼容性含糊（"compatible with most devices"）| 退货率与差评上升 |
| 五点只罗列参数、无使用场景 | 转化率低，买家无法判断是否适合 |
| 使用 "Best" / "2026 NEW" / 促销语 | Listing 被抑制 |
| 认证信息写错或夸大（把非受监管产品标为已获官方批准）| 合规风险，可能下架 |
| 主图加促销角标或水印 | 主图违规，失去购物车资格 |

## 上架检查清单

### 标题
- [ ] ≤ 200 字符，核心数字在前 80 字符内
- [ ] 无全大写、无促销语、无竞品品牌
- [ ] 兼容性写具体机型/系统

### 五点描述
- [ ] 恰好 5 条，每条 ≤ 500 字符
- [ ] 覆盖性能 / 规格 / 兼容 / 认证 / 包装五个角度
- [ ] 无定价、配送、联系方式、评论征集

### 描述
- [ ] ≤ 2000 字符，仅 `<br>` 换行
- [ ] 含兼容与不适配说明
- [ ] 无外链、无促销

### 关键词
- [ ] 后台 Search Terms ≤ 250 字节
- [ ] 未重复标题词，无品牌与 ASIN

### 图片与 A+
- [ ] 主图纯白底、≥ 1000×1000 px
- [ ] 含规格图、兼容图、清单图
- [ ] A+ 无价格、无保证/保修声明、无链接
