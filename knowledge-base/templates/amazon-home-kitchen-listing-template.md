# Home & Kitchen Listing Template

## Overview

The core play for home and kitchen listings is removing doubts about size and material: buyers worry most about whether an item will fit once it arrives, whether the material is safe, and whether it is hard to clean. The title must state the product type, material and capacity or size clearly; the bullet points must give real measured values (with units), specific materials, cleaning and care instructions, and use scenarios. This document provides a structure you can apply directly; the rule boundaries are governed by the specification documents under `platform-rules/`.

## Title Formula

**Formula**: `Brand + Product Type + Material + Capacity/Size + Quantity or Color + Key Feature`

| Point | How to Write It |
|------|------|
| Lead with the product type | State what the item is within the first 80 characters (the mobile truncation window) |
| Make the material specific | Write "Ceramic", "Stainless Steel", "Cotton" and similar; never "Premium" alone |
| Sizes with units | Arabic numerals plus units (12 oz, 10 Inch, 3 Qt) |
| Prohibited | ALL CAPS, promotional language, `!` `*` `$`, restricted terms such as "eco-friendly" |

✅ Good examples:
- `LumiHome Ceramic Coffee Mug Set - 12 oz, Set of 4, Dishwasher and Microwave Safe, Matte Glaze, White`
- `OakLeaf Stainless Steel Mixing Bowl Set - 3 Pieces, 1.5/3/5 Qt, Non-Slip Base, Nesting Design`
- `CozyNest Cotton Throw Blanket - 50 x 60 Inch, Waffle Weave, Machine Washable, Grey`

❌ Counterexample (deliberately non-compliant, shown only to illustrate violations): `LumiHome BEST Mugs!!! Eco-Friendly Premium Quality Free Shipping Buy Now`

## Bullet Points Structure

Five fixed angles; each bullet is ≤ 500 characters, sentence case with a capitalized lead-in, no end-of-sentence punctuation and no promotional language.

| # | Fixed Angle | Example (ready to adapt) |
|----|---------|-------------------|
| 1 | Use scenario and target user | `EVERYDAY MORNING COFFEE - 12 oz capacity suits a latte or americano, and the tapered rim fits most drip brewers` |
| 2 | Material and craftsmanship | `FIRED CERAMIC BODY - Fired at high temperature for a chip-resistant glaze that will not absorb odors or stains` |
| 3 | Size/capacity and fit | `TRUE MEASUREMENTS - 3.5 Inch diameter, 4 Inch height; each mug holds 12 oz and stacks in standard cabinets` |
| 4 | Cleaning, care and durability | `DISHWASHER AND MICROWAVE SAFE - Top-rack dishwasher safe and microwave safe; hand wash to keep the matte glaze bright` |
| 5 | What is in the box and usage tips | `SET OF 4 - Four 12 oz mugs in protective foam; wash before first use; not intended for oven or open flame` |

> The size bullet (bullet 3) matters most for home and kitchen: it must state real measured values, never just "large" or "standard size".

## Description Structure

≤ 2000 characters, `<br>` is the only permitted line break, no external links and no promotional content. Four-paragraph skeleton:

1. **Scenario opener**: how the product fits into daily life (breakfast, storage, hosting guests)
2. **Material and craft**: specific materials, surface finish and durability notes
3. **Size and fit**: full dimensions (including capacity and weight), the spaces it fits, and whether it stacks
4. **Cleaning and care**: how to wash it and the limits of use (for example, not for open flame or freezer)

**Suggested A+ content modules**:

| Module | Purpose |
|------|------|
| Size infographic | Mark length, width, height and capacity to answer "will it fit" |
| Material close-up set | Show glaze, wood grain or fabric texture at close range |
| Cleaning and care graphic | Dishwasher/microwave symbols and care steps |
| Lifestyle image set | Three scenarios: kitchen, dining table, living room |
| Comparison table | Compare capacities and colors within the same series |

## Keyword Placement

| Location | What to Include | What Not to Include |
|------|---------|-----------|
| Title | Brand + category term + material term + size/capacity term | Restricted terms (eco-friendly, antibacterial) and promotional language |
| Bullet points (the first 2 carry the most weight) | Scenario terms, material terms and capacity/size long tails, woven in naturally | Holiday or trending terms unrelated to the product |
| Description | Use scenarios and care-related question long tails ("is it dishwasher safe") | Keyword stuffing |
| Backend Search Terms | Synonyms, material variants and supplementary use terms, ≤ 250 bytes, space-separated | Brand names, ASINs, words already used in the title |

## Common Mistakes in This Category

| Mistake | Consequence |
|------|------|
| Vague sizing ("large", "standard size") | Size mismatch leads to returns and negative reviews |
| Material described only as "high quality", with no specific material | Buyers cannot judge the product; low conversion |
| No cleaning or care information | Negative reviews cluster around "hard to clean" |
| Using restricted terms such as "antibacterial" / "eco-friendly" / "bamboo" | Listing suppressed |
| Unclear set contents (bundled accessories not stated) | Higher return rate |
| Unverified official approval or certification claims | Compliance risk; possible removal |

## Listing Checklist

### Title
- [ ] ≤ 200 characters, with the product type stated in the first 80 characters
- [ ] Includes a specific material and a size or capacity
- [ ] No restricted terms, no promotional language, no ALL CAPS

### Bullet Points
- [ ] Exactly 5 bullets, each ≤ 500 characters
- [ ] Cover the five angles: scenario / material / size / care / box contents
- [ ] Sizes given as real measured values with units
- [ ] No pricing, shipping, contact details or review requests

### Description
- [ ] ≤ 2000 characters, `<br>` line breaks only
- [ ] Includes full dimensions, fit and care information
- [ ] No external links, no promotional content

### Keywords
- [ ] Backend Search Terms ≤ 250 bytes
- [ ] No words repeated from the title, no brands and no ASINs

### Images and A+
- [ ] Main image on a pure white background, ≥ 1000×1000 px
- [ ] Includes size image, material image and care image
- [ ] A+ contains no pricing, no guarantee or warranty claims and no links
