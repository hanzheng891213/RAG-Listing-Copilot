# Electronics Listing Template

## Overview

The core play for electronics listings is specification-driven decisions: buyers have already filtered by specs before they click, so the title must lead with the key numbers (wattage, battery life, capacity, ports), and the bullet points must resolve purchase doubts using spec + scenario + compatibility. This document provides a structure and sample copy you can apply directly; the rule boundaries are governed by the specification documents under `platform-rules/`. Recommended writing order: settle the core specs and compatibility list first, then write the title, and place keywords last.

> Note: products with wireless functionality (Wi-Fi / Bluetooth) require an FCC ID, and plug-in products require UL/ETL reports. See the Product Safety & Compliance documents for details.

## Title Formula

**Formula**: `Brand + Model/Series + Product Type + 2-3 Core Specs + Compatibility/Key Feature + Color or Quantity`

| Point | How to Write It |
|------|------|
| Lead with core numbers | Place hard metrics such as battery life, wattage and capacity within the first 80 characters (the mobile truncation window) |
| Be explicit about compatibility | Name specific models or operating systems instead of "universal" or "most devices" |
| Control length | ≤ 200 characters, 120-160 recommended; do not repeat the same keyword more than twice |
| Prohibited | ALL CAPS, `!` `*` `$`, promotional claims, time-sensitive wording ("2026 NEW"), competitor brand names |

✅ Good examples:
- `AuroraSound XP200 Bluetooth Speaker - IPX7 Waterproof, 24H Playtime, 30W Stereo, USB-C, Black`
- `VoltEdge 65W USB-C Charger - GaN III, 2-Port PD 3.0, Foldable Plug, for Laptops and Phones`
- `NovaTech A7 Wireless Headphones - 40H Battery, Active Noise Cancelling, Bluetooth 5.3, Over-Ear`

❌ Counterexample (deliberately non-compliant, shown only to illustrate violations): `AuroraSound Best Waterproof Speaker!!! 2026 NEW #1 Bluetooth Speaker Free Shipping`

## Bullet Points Structure

Five fixed angles, and their order should not be rearranged. Each bullet is ≤ 500 characters, sentence case with a capitalized lead-in, no end-of-sentence punctuation and no promotional language.

| # | Fixed Angle | Example (ready to adapt) |
|----|---------|-------------------|
| 1 | Core performance and target user | `40 HOURS OF PLAYTIME - A single charge covers a week of commutes and recharges fully in 2 hours via USB-C` |
| 2 | Key hardware specifications | `DUAL 15 W DRIVERS - Two full-range drivers deliver 30 W stereo output with bass down to 60 Hz` |
| 3 | Compatibility and connectivity | `WIDE COMPATIBILITY - Bluetooth 5.3 pairs with iOS, Android, Windows and macOS; 3.5 mm AUX input included` |
| 4 | Protection, certification and build | `IPX7 WATERPROOF AND CERTIFIED - Sealed housing survives 30-minute submersion; FCC and CE certified` |
| 5 | What is in the box and usage tips | `WHAT YOU GET - Speaker, USB-C cable, AUX cable and quick-start guide; charge fully before first use` |

> Suggested writing order: draft bullets 2 and 3 first (specs and compatibility), then fill in bullet 1, and finish with bullet 5.

## Description Structure

≤ 2000 characters, `<br>` is the only permitted line break, no external links and no promotional content. Four-paragraph skeleton:

1. **Scenario opener**: who uses it and in what situation, and what problem it solves (2-3 sentences)
2. **Technical detail**: the specification details behind the bullets, covering what a parameter table cannot carry (for example audio codecs or charging protocols)
3. **Compatibility and fit**: state clearly which systems and models are and are not supported, to reduce returns
4. **Packaging and use**: box contents, first-time setup, routine maintenance

**Suggested A+ content modules** (for Brand Registry sellers):

| Module | Purpose |
|------|------|
| Technical specification comparison table | Compare models within the same series to support selection |
| Compatibility chart | List supported models and systems |
| Lifestyle image set | Three scenarios: commute, office, outdoor |
| Brand story | Build trust; contains no pricing and no promotional content |

## Keyword Placement

| Location | What to Include | What Not to Include |
|------|---------|-----------|
| Title | Brand + core category term + 2-3 high-volume spec terms | Competitor brands, stacked lists of compatible model names |
| Bullet points (the first 2 carry the most weight) | Long-tail terms, spec terms and scenario terms, woven naturally into the first 100 characters | Trending search terms unrelated to the product |
| Description | Use-case terms and question-style long tails ("how to pair") | Keyword stuffing |
| Backend Search Terms | Synonyms, abbreviations, spelling variants, material/scenario supplements, ≤ 250 bytes, space-separated | Brand names, ASINs, words already used in the title |

## Common Mistakes in This Category

| Mistake | Consequence |
|------|------|
| Stuffing the title with compatible brands (Apple Samsung Sony…) | Flagged as keyword stuffing or trademark infringement |
| Vague compatibility ("compatible with most devices") | Higher return rate and more negative reviews |
| Bullet points that only list specs, with no use case | Low conversion; buyers cannot tell whether the product suits them |
| Using "Best" / "2026 NEW" / promotional language | Listing suppressed |
| Incorrect or exaggerated certification claims (marking an unregulated product as officially approved) | Compliance risk; possible removal |
| Promotional badges or watermarks on the main image | Main image violation; loss of Buy Box eligibility |

## Listing Checklist

### Title
- [ ] ≤ 200 characters, with the core numbers inside the first 80 characters
- [ ] No ALL CAPS, no promotional language, no competitor brands
- [ ] Compatibility stated as specific models or systems

### Bullet Points
- [ ] Exactly 5 bullets, each ≤ 500 characters
- [ ] Cover the five angles: performance / specs / compatibility / certification / packaging
- [ ] No pricing, shipping, contact details or review requests

### Description
- [ ] ≤ 2000 characters, `<br>` line breaks only
- [ ] Includes both compatible and incompatible device notes
- [ ] No external links, no promotional content

### Keywords
- [ ] Backend Search Terms ≤ 250 bytes
- [ ] No words repeated from the title, no brands and no ASINs

### Images and A+
- [ ] Main image on a pure white background, ≥ 1000×1000 px
- [ ] Includes spec image, compatibility image and what's-in-the-box image
- [ ] A+ contains no pricing, no guarantee or warranty claims and no links
